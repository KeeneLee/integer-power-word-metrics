# Bilipschitz Equivalence of Integer Power Word Metrics

**Qiao Li** · Public release: November 4, 2026

An English report and Lean 4 formalization of bilipschitz equivalence for all integer signed-power word metrics, including bases 2 and 3.

## Result

For an integer $a\ge 2$, let $d_a$ be the word metric on $\mathbb Z$ generated by $\{\pm a^k:k\ge 0\}$. Thus $d_a(x,y)$ is the minimum number of signed powers of $a$ summing to $y-x$.

For every $a,b\ge 2$, there is a bijection $f:\mathbb Z\to\mathbb Z$ such that, for all $x,y$,

$$d_b(f(x),f(y))\le C(a,b)d_a(x,y),\qquad d_a(x,y)\le C(b,a)d_b(f(x),f(y)),$$

where $C(a,b)=a\bigl(2+35(b^2-1)\bigr)$. In particular, $(\mathbb Z,d_2)$ and $(\mathbb Z,d_3)$ are bilipschitz equivalent, with forward and inverse bounds 564 and 321.

The proof uses relative Hamming recoding that preserves two distinguished symbols and commutes with finite flips, allowing control of arbitrarily long carries. Passing to squared bases covers every base at least two. The formalization uses classical choice and proves existence of the bijection.

Install Lean via [elan](https://github.com/leanprover/elan), then run from this repository:

```sh
cd lean
lake exe cache get
lake build
```
